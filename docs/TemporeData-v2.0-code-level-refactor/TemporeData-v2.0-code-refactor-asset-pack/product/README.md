## 一句话定位

> TemporeData 是一个**前后端合一的单体交付**的企业级数据云平台：`temporedata-ui`（Vue 3 SPA）+ `temporedata-server`（Spring Boot），最终以单个可执行 JAR 同源托管前端静态资源与后端 API，覆盖数据的**研发、资产、服务与治理**全链路。
